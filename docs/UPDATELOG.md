# TrussLab 업데이트 내역

## 2026-10-30

### TrussLab 첫 버전을 만들었습니다

- 1 m 격자 위에 절점·부재·핀·롤러·하중을 놓는 2D 트러스 편집기를 만들었습니다.
- 목재와 강재를 골라 부재를 만들고, 절점을 끌어 옮기고, 확대·축소하고, 실행 취소·다시 실행할 수 있습니다.
- 절점법으로 반력과 부재 힘을 계산하고, 인장(T)·압축(C)·영부재(0)를 색과 글자로 함께 보여 줍니다.
- 정정·부정정·불안정을 구분하고, 평형 행렬의 계수까지 확인해 기구 구조를 잡아냅니다.
- 응력 활용률, 안전율, 비용, 영부재, 오일러 좌굴(K=1.0), 변형(과장)을 계산해 보여 줍니다.
- 10단계 하중 시험으로 첫 파괴 부재와 파괴 이유(응력/좌굴)를 찾고, 붕괴 애니메이션으로 보여 줍니다.
- 같은 해석 결과를 3D 교량으로 표현했습니다. 회전·확대, 데크, 지지대, 하중 화살표, 부재 힘 라벨, 변형과 파괴 애니메이션이 들어갑니다.
- 여섯 개 미션(삼각형, 인장·압축, 6부재 설계, 예산, 영부재, 구조 보수)을 예측 → 설계 → 시험 → 설명 순서로 만들었습니다.
- 진행 상황, 예측 답, 마지막 모델, 보기 설정을 이 브라우저(localStorage)에 저장합니다.
- 교사용 화면에서 정답을 숨기거나 보여 주고, 준비된 모델을 불러오고, 진행을 초기화하고, A4 활동지를 인쇄할 수 있습니다.
- 데스크톱 3열, 태블릿·휴대폰 하단 시트(도구·힘·미션)로 화면을 나눴고, 작은 화면에서는 버튼과 입력칸을 더 크게 만들었습니다.
- 키보드로 절점·부재를 놓고 미션을 끝낼 수 있고, 화면 읽기용 모델 요약과 실제 HTML 힘 표를 넣었습니다.
- 색만으로 T/C를 구분하지 않도록 글자 라벨과 힘 표를 함께 두었고, 동작 줄이기 설정을 존중합니다.
- PWA로 설치할 수 있고, 첫 방문 뒤에는 인터넷 없이 다시 열어도 동작합니다. 서버·로그인·AI 호출은 없습니다.

### 확인한 것

- 단위 테스트 43개가 통과했습니다. 손으로 계산한 삼각형·워런 트러스, 정정/부정정/불안정, 영부재, 좌굴, 비용, 변형, 하중 시험, 여섯 미션의 통과 조건을 확인했습니다.
- 브라우저 테스트 20개가 통과했습니다. 트러스 직접 만들기, 키보드만으로 미션 완료, 예측 오답/정답, 첫 파괴, 3D 전환, 모바일 탭, 교사 초기화·활동지 인쇄, 동작 줄이기, 외부 요청 없음까지 확인했습니다.
- 자동 접근성 검사(axe)에서 심각·치명 문제가 나오지 않았습니다. 디자인·시험·미션·교사·3D·모바일 화면을 검사했습니다.
- 프로덕션 빌드에서 오프라인 새로고침이 정상 동작하는 것을 확인했습니다.
- 초기 자바스크립트는 gzip 약 191 KB, CSS는 약 12 KB입니다.

### 수업용 모델의 한계

- 2D 평면, 핀 절점, 휨 없음, 정정 구조만 해석하는 수업용 모델입니다.
- 좌굴은 핀-핀(K=1.0) 오일러 좌굴 한 가지만 계산하고, 첫 파괴에서 시험을 멈춥니다.
- 재료와 단면 값은 학교 규모에 맞춘 가정값입니다.
- 실제 시공 설계나 안전 인증에 사용할 수 없습니다. 이 안내는 화면 아래와 도움말에 항상 표시됩니다.

### GitHub Pages 배포
- GitHub Actions 워크플로(`.github/workflows/deploy.yml`)를 추가해 `main` 브랜치가 바뀔 때 자동으로 빌드하고 GitHub Pages에 배포하도록 했습니다.
- Pages는 `dist` 정적 파일을 올리는 방식이며, 앱 설치(PWA)와 오프라인 사용도 배포 주소에서 그대로 동작하도록 상대 경로를 확인했습니다.
